# Eminent Forensic Cleaning — Homepage Concept

A premium homepage concept for **Eminent Forensic Cleaning**, a veteran-owned biohazard, forensic, and trauma cleanup company serving Virginia.

This is a **client presentation build** — the homepage shell only, designed to show where the full website can go. It is not the complete site.

## What it is
- Single-page static site (HTML / CSS / vanilla JS) — no build step, fast on mobile.
- Content is drawn from the company's existing website ([bio-eminentfc.com](https://bio-eminentfc.com/)) as the source of truth.
- Real case-work section links to local news coverage of incidents the company responded to.

## Structure
```
index.html      → all page sections
css/styles.css  → design system + components
js/main.js      → nav, reveals, service accordion, case-work data, form
images/         → David Woods Jr. portrait
```

## Local preview
Open `index.html` in a browser, or run any static server:
```
npx serve .
```

## Deploy
Deploys to Vercel with zero configuration (static site).
